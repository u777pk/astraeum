ASTRAEUM サイト一式（HTML + CSS）

【中身】
- index.html : キャラクター一覧
- olive.html : オリーブのプロフィール
- gray.html : グレイのプロフィール
- style.css : 全ページ共通デザイン
- images/ : キャラクター立ち絵を入れる場所

【立ち絵の入れ方】
透過PNGを用意し、images フォルダに
  olive.png
  gray.png
という名前で入れてください。ファイル名は小文字で一致させてください。

【iPhoneでの使い方】
1. ZIPをファイルアプリに保存してタップし、展開します。
2. まず CodePen（https://codepen.io/pen/）をSafariで開きます。
3. index.html の中身をHTML欄へ、style.css の中身をCSS欄へ貼るとトップページの見た目を確認できます。
4. ただし、複数ページと images フォルダを正しい相対パスで動かすには、最終的にはGitHubリポジトリにファイル一式をアップロードし、GitHub Pagesで公開する方法がおすすめです。
5. GitHub Pagesで公開する前に、index.html / olive.html / gray.html / style.css / images フォルダを同じリポジトリのルートに配置してください。

【注意】
プロフィール内容は、ユーザーから共有された設定をもとにした初期文です。必要に応じて各HTMLの文章を編集してください。立ち絵ファイルは含まれていません。
